# Турнир школ стихий — прототип (pygame)

Хотсит-прототип на 4 игроков с одного устройства: выбор школы стихии →
10 дней подготовки (пассивные события + несколько активных действий за
ход, пока хватает энергии) → турнирные бои 1×1 «атака / защита /
способность школы» (полуфинал → финал).

## Запуск

```bash
pip install pygame
python main.py
```

## Структура

- `player.py` — модель игрока: характеристики, энергия подготовки,
  школа стихии, боевые HP/энергия.
- `game_data.py` — таблицы событий (E1–E6), тренировок (T1–T4),
  саботажа (AC5–AC6) и школ стихий (`SCHOOLS`: бонус к характеристике +
  уникальная боевая способность). Добавление новых строк/школ не требует
  правки логики.
- `ui.py` — кнопки, отрисовка текста, панель характеристик, человечек
  (`draw_stick_figure`) и декоративные элементы стихии вокруг него
  (`draw_school_flourish`).
- `states.py` — меню → выбор школ (`SchoolSelectState`) → цикл
  подготовки (`PreparationState`: pass-device → событие → серия действий
  за ход) → экран итогов.
- `battle.py` — финальная мини-игра: атака/защита/способность школы,
  боевая энергия, анимированная схватка человечков, стилизованных под
  стихию, и оркестрация полуфиналов/финала.
- `main.py` — точка входа, игровой цикл.

## Что нового в этой версии

- **Несколько действий за ход.** В фазе действий игрок может тренироваться
  или саботировать соперников подряд, пока хватает энергии — выход из
  хода только по кнопке «Закончить ход ➜».
- **Восстановление энергии подготовки.** В начале хода каждого игрока
  энергия восстанавливается на 50 (до потолка 100) — константа
  `ENERGY_REGEN_PER_TURN` в `states.py`.
- **Кнопки на одном уровне.** «Продолжить» (после передачи устройства) и
  «Далее: действия» (после события) теперь на одной высоте
  (`ADVANCE_BUTTON_Y` в `states.py`).
- **Школы стихий.** Перед подготовкой каждый из 4 игроков выбирает одну
  из 4 школ (огонь/вода/земля/воздух), не пересекаясь с другими. Школа
  даёт +3 к своей характеристике и уникальную боевую способность.
- **Боевая энергия и способности.** В мини-игре у каждого бойца есть
  энергия (макс. = 50 + concentration×2, старт — половина). В начале
  каждого хода бойца она восстанавливается на 20 (`BATTLE_ENERGY_REGEN`
  в `battle.py`). Способности:
  - 🔥 Огонь — «Огненный шар»: урон ×2.2, дороже всего (35 эн.).
  - 💧 Вода — «Целебный поток»: сразу восстанавливает 26 HP (30 эн.).
  - 🪨 Земля — «Каменная броня»: усиленный блок, отражающий часть
    урона обратно атакующему (25 эн.).
  - 🌪️ Воздух — «Порыв ветра»: удар, игнорирующий блок соперника (20 эн.).
- **Стилизация человечков.** Каждая фигура рисуется в цвете своей школы
  и окружена декоративными элементами: языки пламени, капли воды,
  камни у ног, вихрь воздуха — с лёгкой анимацией.

## Что упрощено в прототипе (сознательно)

- Картинки событий/действий подготовки — эмодзи-плейсхолдеры (поле
  `placeholder` в `game_data.py`), легко заменить на `pygame.image.load(...)`.
- Имена игроков фиксированы («Игрок 1»–«Игрок 4»).
- Формулы шансов/урона (`success_chance`, расчёт `dmg` в `battle.py`,
  стоимости способностей) — грубая рабочая прикидка, требует баланса
  под ваши ощущения от игры.
- В `game_data.py` под E3–E6 и AC5–AC6 — содержательные заготовки
  взамен пустых строк концепта, замените по вкусу.

Весь код прошёл автоматическую проверку (headless-прогон полного цикла:
выбор школ → несколько действий за ход в подготовке → бой со
способностями → итоги) на нескольких случайных сидах — работает без
ошибок.
