# Турнир школ стихий — прототип (pygame)

Хотсит-прототип на 4 игроков с одного устройства: 10 дней подготовки
(пассивные события + активные действия — тренировки/саботаж), затем
турнирные бои 1×1 в формате «атака / защита» (полуфинал → финал).

## Запуск

```bash
pip install pygame
python main.py
```

## Структура

- `player.py` — модель игрока: характеристики, энергия, журнал.
- `game_data.py` — таблицы событий (E1–E6), тренировок (T1–T4) и
  саботажа (AC5–AC6). Добавление новых строк не требует правки логики —
  можно смело дозаполнять таблицы.
- `ui.py` — кнопки, отрисовка текста, панель характеристик игрока.
- `states.py` — меню, цикл подготовки (10 дней × 4 игрока: pass-device →
  событие → действие → результат), экран итогов.
- `battle.py` — финальная мини-игра (атака/защита): анимированная схватка
  двух человечков (выпад атаки, отдача/вспышка при попадании, стойка щита,
  падение при поражении, всплывающие цифры урона) и оркестрация
  полуфиналов/финала. Логика урона и шансов не менялась — только визуализация.
- `main.py` — точка входа, игровой цикл.

## Что упрощено в прототипе (сознательно)

- Картинки событий/действий — эмодзи-плейсхолдеры (поле `placeholder`
  в `game_data.py`), легко заменить на `pygame.image.load(...)`.
- Имена игроков фиксированы («Игрок 1»–«Игрок 4») — можно добавить
  экран ввода имён в `MenuState`.
- Саму формулу шансов и урона в бою (`success_chance`, расчёт `dmg` в
  `battle.py`) стоит сбалансировать под ваши ощущения от игры —
  сейчас это грубая рабочая прикидка.
- В `game_data.py` под E3–E6 и AC5–AC6 уже есть содержательные
  заготовки взамен пустых строк концепта — при желании замените
  текстами/эффектами по своему вкусу.

Весь код прошёл автоматическую проверку (headless-прогон полного
цикла игры на нескольких случайных сидах) — запускается и доигрывается
до экрана итогов без ошибок.
