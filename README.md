# Турнир Четырёх Стихий

Пошаговая PvP-игра на Python/Pygame для четырёх игроков за одним компьютером.

## Запуск

```bash
python -m pip install -r requirements.txt
python main.py
```

Для тестов:

```bash
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
```

## Анимация боя

Центральная арена использует стилизованных человечков, как в примере `пв.txt`:
выпад с небольшим смещением, вспышка при попадании, визуальный щит, падение
побеждённого и всплывающие числа урона/лечения. Для школ добавлены лёгкие
декоративные эффекты огня, воды, земли и воздуха. Анимация не блокирует цикл
Pygame; правила боя применяются один раз в момент удара, а после нокаута арена
остаётся на экране до окончания анимации падения.

На экране боя арена расположена между карточками чемпионов и сокращённой
«Хроникой турнира». Размеры и длительности анимации настраиваются в `config.py`.

## Примечание об исходных материалах

Текстовый дамп исходного проекта не включал бинарные PNG-иконки. Поэтому
`ui/panel.py` использует исходные изображения, если они доступны, и автоматически
рисует простые векторные значки школ, если файлов нет.
